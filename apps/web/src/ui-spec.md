# Paradox AI UI/UX Spec

## Visual language
- Dark neon base: `#06070A` with electric blue/purple accents
- Glassmorphism surfaces with 12-20px blur
- Gradient borders on cards and CTA controls
- Animated particles and depth parallax
- Micro-interactions for every primary actionable element

## Key interaction primitives
- Floating navigation rail
- Command palette (`Cmd/Ctrl + K`)
- Inertia-driven smooth scroll
- AI typing animation in chat and onboarding
- Dynamic analytics cards with live counters
- Custom animated cursor (desktop only)

## Accessibility baseline
- WCAG AA color contrast
- Keyboard-first navigation maps
- Reduced motion fallback for all animations
- Screen-reader labels for dynamic controls
