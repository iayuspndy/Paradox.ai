# Paradox AI

**Tagline:** _Where Ideas Become Reality._

Paradox AI is a unified AI platform that combines:
- AI Super Chat
- Deep Research
- Autonomous Website Builder
- Full-Stack App Builder
- Automation Builder
- SaaS-in-10-Minutes generator

This repository contains a production-grade reference architecture, implementation blueprint, and deploy-ready foundation for building Paradox AI as a multi-tenant SaaS.

## Monorepo Layout

- `apps/web` — Next.js frontend (chat studio, builders, dashboards)
- `apps/api` — Node.js backend services, agent orchestration, billing, deployments
- `apps/api/prisma` — PostgreSQL schema
- `infra` — Docker + infrastructure templates
- `docs` — system architecture, deployment, scaling, monetization and GTM

## Product Experience Pillars

1. **Think** — AI Super Chat + Deep Research
2. **Build** — Website/App/SaaS generators with autonomous agent collaboration
3. **Deploy** — one-click infrastructure provisioning, domains, CI/CD, observability
